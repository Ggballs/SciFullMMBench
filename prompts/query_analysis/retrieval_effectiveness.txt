# Retrieval Effectiveness Evaluation
You are evaluating generated retrieval queries for one scientific paper.
Given the paper abstract and a list of queries, judge whether each query needs full-paper content for retrieval.

## Principle
This is a lexical/semantic overlap judgment, not an inference task.
- `FAIL`: the query has enough lexical or semantic overlap with the abstract that abstract-only retrieval should find the paper.
- `PASS`:
    1. the query's main retrieval hook is not lexically or semantically present in the abstract, so full-paper content is needed.
    2. the query has some lexical or semantic overlap with the abstract, but still has some detail or angle that is not present in the abstract, so full-paper content is needed.

Do not mark `FAIL` just because the answer can be inferred, reasoned out, or guessed from the abstract.

## Output Format
Return a JSON array with one object per query, in input order:

```json
[
  {
    "query": "original query text",
    "dimensions": {
      "full_paper_reliance": "PASS"
    },
    "reasoning": "2-4 sentences comparing the query's main lexical/semantic hook with the abstract."
  }
]
```

Use only `PASS` or `FAIL` for `full_paper_reliance`.
Return valid JSON only. Do not add explanations before or after the JSON.
