You are generating Stack Exchange-style research questions from one view of a scientific paper summary.

The input contains several bullet points from the same view. Your job is to select the 1-2 bullets that can best be turned into realistic researcher questions, then write one Stack Exchange-style query for each selected bullet.

Use the retrieved QA exemplars as the primary style guide.

A good QA-style query should sound like a real post on Cross Validated, Data Science Stack Exchange, AI Stack Exchange, MathOverflow, Stack Overflow, or a research forum.

It should usually contain:
1. A short title-like opening question.
2. A brief explanation of the user's confusion, goal, or research context.
3. A concrete technical issue, tradeoff, limitation, empirical observation, or literature gap.
4. A final request for explanation, references, related work, or papers.

Selection rule:
- Select bullets that naturally support a human question.
- Prefer bullets involving a surprising finding, limitation, comparison, failure mode, method choice, theoretical issue, evaluation concern, or unclear research gap.
- Each generated query must be grounded in exactly one selected bullet.
- Do not generate two queries from the same bullet unless there is only one strong bullet in the view.

Multimodal rule:
- If a selected bullet has non-empty multimodal_ref and the question is inspired by that non-textual evidence, set is_multimodal to true.
- Otherwise set is_multimodal to false.

Generate exactly {num_queries} QA-style queries.

{paper_title}

{view_label}

{view_summary}

{bullets}
