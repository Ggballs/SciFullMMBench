# Retrieval Effectiveness Evaluation
You are evaluating generated retrieval queries for one scientific paper.
Given the paper abstract and a list of queries, judge whether each query needs full-paper content for retrieval.

## Principle
Judge whether a keyword-based retriever using only the abstract could find this paper for the query. This is a lexical and semantic overlap judgment, not an inference task.

Lexical means exact word matches. Synonyms, paraphrases, and conceptual equivalents are semantic overlap, not lexical.

Three levels, check lexical overlap first, then semantic:

- `HIGH-LEXICAL-OVERLAP`: EVERY key retrieval term appears verbatim in the abstract. An abstract-only keyword retriever would succeed.
- `LOW-LEXICAL-OVERLAP`: at least one key term or phrase does NOT appear verbatim in the abstract. a keyword retriever would miss the paper. Full-paper content is needed.
- `LOW-SEMANTIC-OVERLAP`: key terms are NOT in the abstract AND the angle or aspect is also NOT covered by the abstract. Both lexical and semantic overlap are low. Full-paper content is needed.

Hard rule: if ANY key retrieval term is expressed through synonyms, paraphrases, or different wording rather than appearing verbatim, the query CANNOT be HIGH-LEXICAL-OVERLAP. It is LOW-LEXICAL-OVERLAP (same angle) or LOW-SEMANTIC-OVERLAP (different angle).
Do not mark `HIGH-LEXICAL-OVERLAP` just because the answer can be inferred or reasoned out from the abstract. Only mark it when the actual words and the actual discussion point both match.

## Output Format
Return a JSON array with one object per query, in input order:

```json
[
  {
    "query": "original query text",
    "dimensions": {
      "abstract_relevance": "LOW-LEXICAL-OVERLAP"
    },
    "reasoning": "1) Key retrieval terms: [list them]. 2) Per-term check: for each term, does it appear VERBATIM in the abstract (morphological variants like plurals ok)? 3) Angle check: does the abstract discuss the same aspect? 4) Conclusion: ALL terms verbatim + same angle = HIGH-LEXICAL-OVERLAP; any term missing but same angle = LOW-LEXICAL-OVERLAP; terms missing + angle differs = LOW-SEMANTIC-OVERLAP."
  }
]
```

Use only `HIGH-LEXICAL-OVERLAP`, `LOW-LEXICAL-OVERLAP`, or `LOW-SEMANTIC-OVERLAP` for `abstract_relevance`.
Return valid JSON only. Do not add explanations before or after the JSON.
